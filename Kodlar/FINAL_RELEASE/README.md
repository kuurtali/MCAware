# Nihai Yayın Paketi (FINAL_RELEASE)

Bu klasör, araştırmanın nihai aşamasında koşturulan onaylı deney kodlarını ve görselleştirme scriptlerini içerir. Toplam 8 dosya bulunmaktadır.

## (1) Sektörel Testler
- `01_Sektorel_Karsilastirma_Sigorta.R`: Sigorta sektörü ilk analizi (v1).
- `01_Sektorel_Karsilastirma_Sigorta_v2.R`: Seed-fix uygulanmış nihai sigorta analizi (v2).
- `02_Sektorel_Karsilastirma_Holding.R`: Holding sektörü analizi.

## (2) Dayanıklılık Testi
- `03_Robustness_Check_Attention.R`: BiLSTM + Multi-Head Attention mimarisi ile dayanıklılık testi.

## (3) Görselleştirme
- `04_mcaware_visualize_results.R`: Temel sonuçların görselleştirilmesi.
- `05_mcaware_advanced_visuals.R`: İleri düzey grafikler.
- `06_mcaware_exhaustive_visuals.R`: Ekstra / detaylı grafikler.
